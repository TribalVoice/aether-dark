# Aether Dark

Dual-voice drone instrument in the Aether series. Browser-based: two analog-style voices, Drift LFO, Evolve climate, noise, tape print, echo, bloom, patchbay, MIDI.

**Play:** open this repo’s GitHub Pages URL in Chrome, Edge, or (on iPad) Safari.

`https://YOURUSER.github.io/aether-dark/`

**iPad:** that https link in Safari. Do not open the HTML from the Files app preview.

**PC offline:** download `index.html` and open it in Chrome or Edge.

**Manual:** [Aether-Dark-User-Manual.pdf](Aether-Dark-User-Manual.pdf)

**Support:** [ko-fi.com/tribalvoice](https://ko-fi.com/tribalvoice)
